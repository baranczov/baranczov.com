Резюме Данила Баранцова

Файлы:
  CV_Barantsov_Danil.pdf  — готовое двухстраничное резюме.
  CV_Barantsov_Danil.docx — редактируемая Word-версия с тем же содержанием.
  main.tex              — полный исходник LaTeX в UTF-8.
  build.sh              — сборка PDF двумя проходами pdfLaTeX.

Сборка на macOS / Linux:
  sh build.sh

Нужен TeX Live / MacTeX с пакетами babel-russian, cyrillic, cm-super,
cmap, geometry, enumitem, titlesec и hyperref. Полная установка MacTeX
содержит эти пакеты. На Windows с MiKTeX или TeX Live выполните дважды:
  pdflatex -interaction=nonstopmode -halt-on-error main.tex
Результат ручной сборки — main.pdf.

Overleaf: загрузите main.tex, выберите компилятор pdfLaTeX.
Внешние шрифты, изображения и сетевые запросы для сборки не нужны.
PDF — основная версия с проверенной версткой. Пагинация Word может
зависеть от установленного шрифта и версии редактора.
